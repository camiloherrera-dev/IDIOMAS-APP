## Tres géneros en vez de dos

El español tiene masculino y femenino. El alemán tiene **tres** géneros, y cada uno tiene su artículo:

| Género | Artículo definido | Artículo indefinido | Ejemplo |
| --- | --- | --- | --- |
| Masculino | **der** | **ein** | **der / ein Tisch** (la mesa) |
| Femenino | **die** | **eine** | **die / eine Lampe** (la lámpara) |
| Neutro | **das** | **ein** | **das / ein Buch** (el libro) |
| Plural | **die** | (no hay) | **die Bücher** (los libros), **Bücher** (libros) |

**El género alemán no coincide con el español.** "La mesa" es femenina en español, pero **der Tisch** es masculino. "El sol" es masculino, pero **die Sonne** es femenino. "La luna" es femenina, pero **der Mond** es masculino. No traduzcas el género: apréndelo.

**La regla más importante de esta guía:** aprende **siempre** cada sustantivo con su artículo y su plural, como si fueran una sola palabra: no "Tisch", sino **der Tisch, die Tische**. En tus tarjetas puedes usar colores: azul para der, rojo para die, verde para das.

```ejemplos
Der Tisch ist neu. | La mesa es nueva.
Die Lampe ist schön. | La lámpara es bonita.
Das Buch ist interessant. | El libro es interesante.
Das ist ein Stuhl. | Eso es una silla.
Das ist eine Tasse. | Eso es una taza.
```

## El sexo natural

Las personas y animales con sexo claro suelen seguirlo: **der Mann** (el hombre), **die Frau** (la mujer), **der Vater**, **die Mutter**, **der Sohn**, **die Tochter**. Pero hay excepciones famosas: **das Mädchen** (la niña) y **das Kind** (el niño, la niña) son neutros.

## Trucos para adivinar el género

No hay reglas perfectas, pero muchas terminaciones ayudan mucho:

**Casi siempre femenino (die):**

| Terminación | Ejemplos |
| --- | --- |
| **-ung** | die Wohnung, die Zeitung, die Übung |
| **-heit**, **-keit** | die Freiheit, die Gesundheit, die Möglichkeit |
| **-schaft** | die Freundschaft, die Mannschaft |
| **-ion** | die Station, die Nation, die Information |
| **-tät** | die Universität, die Qualität |
| **-ie**, **-ik** | die Familie, die Musik, die Politik |
| **-in** (mujeres) | die Lehrerin, die Ärztin, die Freundin |
| **-e** (muchas, no todas) | die Lampe, die Tasse, die Straße |

**Casi siempre neutro (das):**

| Terminación | Ejemplos |
| --- | --- |
| **-chen**, **-lein** (diminutivos) | das Mädchen, das Brötchen, das Fräulein |
| **-um** | das Museum, das Zentrum, das Datum |
| **-ment** | das Instrument, das Dokument |
| Verbos usados como sustantivo | das Essen, das Leben, das Schwimmen |

**-chen**, **-lein** y los verbos usados como sustantivo son **siempre** neutros; con **-um** y **-ment** hay algunas excepciones (**der Moment**, **der Konsum**).

**Normalmente masculino (der):**

| Terminación o grupo | Ejemplos |
| --- | --- |
| **-er** de personas que hacen algo | der Lehrer, der Fahrer, der Bäcker |
| **-ismus** | der Tourismus |
| **-ling** | der Frühling, der Lehrling |
| Días, meses, estaciones | der Montag, der Mai, der Sommer |
| Puntos cardinales, clima | der Norden, der Regen, der Schnee |
| Marcas de carros | der BMW, der VW |

**Palabras compuestas:** el género lo decide **la última palabra**. **das Haus** + **die Tür** = **die Haustür** (la puerta de la casa). **der Kaffee** + **die Tasse** = **die Kaffeetasse**.

```ejemplos
Die Wohnung ist groß. | El apartamento es grande.
Das Mädchen heißt Lena. | La niña se llama Lena.
Der Lehrer kommt aus Österreich. | El profesor es de Austria.
Die Lehrerin kommt aus der Schweiz. | La profesora es de Suiza.
```

## Profesiones: masculino y femenino

Para la forma femenina se agrega **-in** (y a veces Umlaut). En plural, **-innen**:

| Masculino | Femenino | Plural femenino |
| --- | --- | --- |
| der Lehrer | die Lehrer**in** | die Lehrerinnen |
| der Student | die Student**in** | die Studentinnen |
| der Arzt | die **Ä**rzt**in** | die Ärztinnen |
| der Koch | die K**ö**ch**in** | die Köchinnen |

Recuerda: con **sein** no se usa artículo para la profesión: **Ich bin Lehrerin.**

## El plural: cinco tipos principales

El plural en alemán tiene varias formas, por eso se aprende con cada palabra. El artículo del plural es **siempre die**, sin importar el género.

| Tipo | Ejemplo singular | Plural | Típico para |
| --- | --- | --- | --- |
| **-e** (a veces con Umlaut) | der Tisch, der Stuhl | die Tisch**e**, die St**ü**hl**e** | muchos masculinos |
| **-(e)n** | die Lampe, die Frau | die Lampe**n**, die Frau**en** | casi todos los femeninos |
| **-er** (con Umlaut si se puede) | das Kind, das Buch | die Kind**er**, die B**ü**ch**er** | muchos neutros cortos |
| **sin cambio** (a veces Umlaut) | der Lehrer, der Vater | die Lehrer, die V**ä**ter | terminados en -er, -el, -en, -chen |
| **-s** | das Auto, das Handy | die Auto**s**, die Handy**s** | palabras extranjeras, terminadas en vocal |

**Trucos:**
- Los femeninos casi siempre hacen el plural con **-(e)n**: **die Wohnung, die Wohnungen**; **die Lehrerin, die Lehrerinnen**.
- Las palabras en **-chen**, **-lein**, **-er**, **-el** no cambian (o solo añaden Umlaut): **das Brötchen, die Brötchen**; **der Löffel, die Löffel**.
- **-s** es el plural de palabras extranjeras, como en español: **das Hotel, die Hotels**; **das Kino, die Kinos**.

```ejemplos
Ich habe zwei Kinder. | Tengo dos hijos.
Die Stühle sind neu. | Las sillas son nuevas.
Wo sind die Brötchen? | ¿Dónde están los panecitos?
In Berlin gibt es viele Museen. | En Berlín hay muchos museos.
```

## Pronombres de tercera persona según el género

Para cosas también se usa el pronombre según el género gramatical, no "eso": **der Tisch → er**, **die Lampe → sie**, **das Buch → es**.

```ejemplos
Wo ist der Schlüssel? Er ist hier. | ¿Dónde está la llave? Está aquí.
Wie ist die Wohnung? Sie ist sehr hell. | ¿Cómo es el apartamento? Es muy luminoso.
```

## Errores típicos de hispanohablantes

- Copiar el género del español: ~~die Tisch~~ → **der Tisch**.
- Agregar **-s** a todo como en español: ~~die Tischs~~ → **die Tische**.
- Usar artículo con profesiones: ~~Ich bin ein Student~~ → **Ich bin Student.**
- Olvidar la mayúscula de los sustantivos: **die Wohnung**, no "die wohnung".
