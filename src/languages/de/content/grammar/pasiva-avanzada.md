## Punto de partida

Ya conoces la pasiva con **werden + Partizip II** (**Das Haus wird gebaut.**) y con un modal en presente (**Das Haus muss gebaut werden.**). En B2 necesitas tres cosas más:

1. la pasiva con modal en **todos los tiempos**;
2. la **pasiva sin sujeto**;
3. las **alternativas** que usan los textos para no repetir siempre "kann … werden".

## Pasiva con modales en todos los tiempos

La base es siempre el **infinitivo pasivo**: **Partizip II + werden**. Lo que se conjuga es el **modal**.

| Tiempo | Forma | Ejemplo |
| --- | --- | --- |
| Präsens | modal + PII + werden | Das Problem **muss gelöst werden**. |
| Präteritum | modal en Präteritum + PII + werden | Das Problem **musste gelöst werden**. |
| Perfekt | hat + PII + werden + modal (infinitivo) | Das Problem **hat gelöst werden müssen**. |
| Plusquamperfekt | hatte + PII + werden + modal | Das Problem **hatte gelöst werden müssen**. |
| Futur I | wird + PII + werden + modal | Das Problem **wird gelöst werden müssen**. |
| Konjunktiv II presente | müsste / könnte / sollte + PII + werden | Das Problem **müsste gelöst werden**. |
| Konjunktiv II pasado | hätte + PII + werden + modal | Das Problem **hätte gelöst werden müssen**. |

En la práctica, para el pasado se usa casi siempre el **Präteritum** (**musste gelöst werden**); el Perfekt con tres verbos al final es correcto, pero pesado. El **Konjunktiv II pasado** sí es muy frecuente: sirve para criticar lo que no se hizo.

### En la subordinada

| Tiempo | Orden al final |
| --- | --- |
| Präsens | …, dass das Problem gelöst werden **muss**. |
| Präteritum | …, dass das Problem gelöst werden **musste**. |
| Perfekt | …, dass das Problem **hat** gelöst werden müssen. |
| Konjunktiv II pasado | …, dass das Problem **hätte** gelöst werden müssen. |

Con **hat / hätte** y dos infinitivos (werden + modal), el auxiliar va **delante** del grupo verbal, no al final.

```ejemplos
Die Rechnung muss bis Freitag bezahlt werden. | La factura tiene que pagarse hasta el viernes.
Das Konzert musste wegen des Regens verschoben werden. | Hubo que aplazar el concierto por la lluvia.
Der Fehler hätte früher bemerkt werden müssen. | El error habría debido notarse antes.
Die Gäste hätten rechtzeitig informiert werden sollen. | A los huéspedes habría habido que informarles a tiempo.
Das Formular kann auch online ausgefüllt werden. | El formulario también se puede llenar en línea.
Ich glaube, dass der Vertrag noch geändert werden kann. | Creo que el contrato todavía se puede cambiar.
Hier darf nicht geparkt werden. | Aquí no se puede parquear.
```

**No confundas** el modal de la pasiva con el Futur: **Das Haus wird gebaut werden** (será construida) es futuro de la pasiva y no lleva modal.

## La pasiva sin sujeto

Con verbos que **no tienen objeto en acusativo** (arbeiten, tanzen, helfen, diskutieren, warten…) se puede formar una pasiva **sin sujeto**. Importa solo la acción; quien la hace son "personas" en general.

- El verbo va **siempre en tercera persona del singular**: **wird, wurde, ist … worden**.
- Si no hay nada más en la primera posición, se pone **es** como relleno. Ese **es** desaparece cuando otro elemento ocupa la primera posición.

| Con es en posición 1 | Con otro elemento en posición 1 |
| --- | --- |
| **Es** wird hier viel gearbeitet. | Hier wird viel gearbeitet. |
| **Es** wurde bis Mitternacht getanzt. | Bis Mitternacht wurde getanzt. |
| **Es** wurde lange über den Plan diskutiert. | Über den Plan wurde lange diskutiert. |
| **Es** wird mir nicht geholfen. | Mir wird nicht geholfen. |

Los complementos en **dativo** o con **preposición** se quedan como están: **Man hilft dem Mann** → **Dem Mann wird geholfen** (no ~~Der Mann wird geholfen~~).

También sirve para dar **órdenes enérgicas**: **Jetzt wird geschlafen!** (¡A dormir!).

Solo funciona con acciones que hacen **personas**. No se dice ~~Es wird geregnet~~.

```ejemplos
In Deutschland wird viel über das Wetter gesprochen. | En Alemania se habla mucho del clima.
Auf der Feier wurde viel gelacht. | En la fiesta se rieron mucho.
Darüber ist schon oft geschrieben worden. | Sobre eso ya se ha escrito muchas veces.
Den Opfern muss schnell geholfen werden. | Hay que ayudar rápido a las víctimas.
Sonntags wird bei uns nicht gearbeitet. | Los domingos en nuestra casa no se trabaja.
Jetzt wird aufgeräumt! | ¡A ordenar ya!
```

## Alternativas a la pasiva

Las cinco oraciones siguientes dicen lo mismo: "El problema se puede resolver".

| Forma | Ejemplo |
| --- | --- |
| Pasiva con modal | Das Problem **kann gelöst werden**. |
| man | **Man kann** das Problem **lösen**. |
| sich lassen + infinitivo | Das Problem **lässt sich lösen**. |
| sein + zu + infinitivo | Das Problem **ist zu lösen**. |
| Adjetivo en -bar | Das Problem **ist lösbar**. |

### sich lassen + infinitivo

Equivale a **kann + Partizip II + werden**: algo "se deja" hacer. El sujeto es la cosa; **lassen** se conjuga normalmente.

| Tiempo | Ejemplo |
| --- | --- |
| Präsens | Das Fenster **lässt sich** nicht **öffnen**. |
| Präteritum | Das Fenster **ließ sich** nicht **öffnen**. |
| Perfekt | Das Fenster **hat sich** nicht **öffnen lassen**. |
| Konjunktiv II | Das **ließe sich** leicht **ändern**. |

```ejemplos
Das lässt sich leicht erklären. | Eso se puede explicar fácilmente.
Die Buchung lässt sich kostenlos stornieren. | La reserva se puede cancelar gratis.
Der Fleck ließ sich nicht entfernen. | La mancha no se pudo quitar.
Das lässt sich nicht vermeiden. | Eso no se puede evitar.
Darüber lässt sich streiten. | Eso es discutible.
```

### sein + zu + infinitivo

Tiene sentido pasivo y puede significar **posibilidad** (kann) o **necesidad** (muss, soll). Lo decide el contexto: con **leicht, schwer, kaum, nicht** suele ser posibilidad; en reglas, plazos e instrucciones, obligación.

| Ejemplo | Equivale a |
| --- | --- |
| Der Text **ist** leicht **zu verstehen**. | Der Text **kann** leicht verstanden werden. |
| Der Lärm **ist** kaum **zu ertragen**. | Der Lärm **kann** kaum ertragen werden. |
| Die Arbeit **ist** bis Montag **einzureichen**. | Die Arbeit **muss** bis Montag eingereicht werden. |
| Die Regeln **sind zu beachten**. | Die Regeln **müssen** beachtet werden. |
| Das Fenster **ist nicht zu öffnen**. | Das Fenster **kann / darf** nicht geöffnet werden. |

Con verbos separables, **zu** va en el medio: **einzureichen, auszufüllen, abzugeben**.

```ejemplos
Die Kosten sind innerhalb von zwei Wochen zu erstatten. | Los costos deben reembolsarse en un plazo de dos semanas.
Diese Frage ist schwer zu beantworten. | Esta pregunta es difícil de responder.
Von hier aus ist das Meer nicht zu sehen. | Desde aquí no se ve el mar.
Der Ausweis ist am Eingang zu zeigen. | El documento debe mostrarse en la entrada.
Was ist jetzt zu tun? | ¿Qué hay que hacer ahora?
```

Ojo con **haben + zu + infinitivo**: es **activo** y significa "tener que": **Ich habe viel zu tun.** (Tengo mucho que hacer.)

### Adjetivos en -bar y -lich

**-bar** se añade a la raíz del verbo y significa "que se puede…": es el **-able / -ible** del español. La negación se hace con **un-**.

| Verbo | Adjetivo | Significado | Negación |
| --- | --- | --- | --- |
| lösen | lösbar | que se puede resolver | unlösbar |
| essen | essbar | comestible | nicht essbar |
| trinken | trinkbar | potable | nicht trinkbar |
| erreichen | erreichbar | localizable, alcanzable | unerreichbar |
| bezahlen | bezahlbar | pagable, asequible | unbezahlbar |
| vergleichen | vergleichbar | comparable | nicht vergleichbar |
| machen | machbar | factible | nicht machbar |
| lesen | lesbar | legible | unlesbar |
| brauchen | brauchbar | utilizable, que sirve | unbrauchbar |
| sehen | sichtbar (irregular) | visible | unsichtbar |

Algunos adjetivos en **-lich** tienen el mismo sentido, pero no se pueden formar libremente: hay que aprenderlos.

| Adjetivo | Significado |
| --- | --- |
| verständlich / unverständlich | que se entiende / que no se entiende |
| unvergesslich | inolvidable |
| unglaublich | increíble |
| erhältlich | que se consigue (en tiendas) |
| unerträglich | insoportable |
| unbeschreiblich | indescriptible |
| käuflich | que se puede comprar |

```ejemplos
Die Miete ist kaum noch bezahlbar. | El arriendo ya casi no se puede pagar.
Ich bin heute bis 18 Uhr erreichbar. | Hoy estoy localizable hasta las 6 de la tarde.
Seine Schrift ist leider unlesbar. | Lastimosamente su letra es ilegible.
Das Wasser hier ist nicht trinkbar. | El agua de aquí no es potable.
Das Buch ist in jeder Buchhandlung erhältlich. | El libro se consigue en cualquier librería.
Die Reise war ein unvergessliches Erlebnis. | El viaje fue una experiencia inolvidable.
```

## Errores típicos

- **Olvidar werden con el modal:** ~~Das Problem muss gelöst~~ → **Das Problem muss gelöst werden**.
- **Participio del modal en el Perfekt:** ~~hat gelöst werden gemusst~~ → **hat gelöst werden müssen**.
- **worden con modal:** ~~Das muss gemacht worden~~ → **Das muss gemacht werden**. **Worden** solo aparece en el Perfekt de la pasiva sin modal (**ist gemacht worden**) o en suposiciones (**muss gemacht worden sein**).
- **Poner el dativo en nominativo:** ~~Ich wurde geholfen~~ → **Mir wurde geholfen**.
- **Dejar el es cuando no hace falta:** ~~Hier wird es viel gearbeitet~~ → **Hier wird viel gearbeitet**.
- **Olvidar sich:** ~~Das lässt leicht erklären~~ → **Das lässt sich leicht erklären**.
- **Poner Partizip II después de lassen o de sein zu:** ~~Das lässt sich gelöst~~, ~~Das ist zu gelöst~~ → **Das lässt sich lösen**, **Das ist zu lösen**. Las dos llevan **infinitivo**.
- **Calcar "es posible de":** ~~Das ist möglich zu lösen~~ → **Das ist zu lösen / Das ist lösbar / Das lässt sich lösen**.
- **Confundir sein zu y haben zu:** **Die Aufgabe ist zu machen** (hay que hacerla, pasivo) frente a **Ich habe die Aufgabe zu machen** (tengo que hacerla, activo).
