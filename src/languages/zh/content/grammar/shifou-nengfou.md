En lectura HSK 4 aparecen equivalentes escritos de palabras cotidianas:

| Formal | Cotidiano | Ejemplo |
| --- | --- | --- |
| **是否** | 是不是 | 我不知道他**是否**同意 |
| **能否** | 能不能 | **能否**成功，要看你自己 |
| **将** | 会 / 要 | 会议**将**在明天举行 |
| **已** | 已经 | 问题**已**解决 |
| **仍 / 仍然** | 还是 | 他**仍然**住在那儿 |
| **并 / 并且** | 而且 | 讨论**并**通过了计划 |
| **与** | 跟 / 和 | 我**与**他是同学 |
| **此** | 这 | **此**外 · 因**此** |
| **无** | 没有 | **无**人 · **无**法 |
| **如** | 像 / 比如 | 例**如** |
| **之** | 的 | 朋友**之**间 · 三分**之**一 |
| **者** | …的人 | 记**者** · 作**者** |

## 并 + 不 / 没

**并不 / 并没有** refuerza una negación contra lo esperado: 这个题**并不**难 (en realidad no es difícil).

## Fracciones y porcentajes

三**分之**一 = 1/3 · **百分之**二十 = 20 %.

## Ejemplos

```ejemplos
我不知道他是否同意。 | No sé si está de acuerdo.
比赛将在明天上午举行。 | La competencia se realizará mañana por la mañana.
十年过去了，他仍然住在那儿。 | Pasaron diez años y sigue viviendo allá.
这个问题并不难。 | Este problema en realidad no es difícil.
我无法回答这个问题。 | No tengo cómo responder esta pregunta.
朋友之间应该互相尊重。 | Entre amigos debe haber respeto mutuo.
你能否把详细情况告诉我？ | ¿Podrías contarme la situación en detalle?
```
