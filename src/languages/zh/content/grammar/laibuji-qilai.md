## Potenciales fijos

| Forma | Sentido |
| --- | --- |
| **来得及 / 来不及** | alcanzar / no alcanzar a tiempo |
| **受不了** | no aguantar |
| **忍不住** | no poder contenerse |
| **舍不得** | no querer desprenderse |
| **看不起** | despreciar |
| **…不了** (liǎo) | no poder…: 去**不了**, 吃**不了** |
| **…得起 / 不起** | poder / no poder pagar: 买**不起** |

## Direcciones figuradas

| Forma | Sentido | Ejemplo |
| --- | --- | --- |
| **起来** | empezar; al…; juntar | 说**起来**容易 · 想**起来**了 |
| **下去** | seguir | 坚持**下去** |
| **下来** | fijar, quedar | 停**下来** · 记**下来** |
| **出来** | hacer surgir, reconocer | 看**出来** · 想**出来** |
| **上** | lograr, cerrar, añadir | 考**上**大学 · 关**上** · 写**上** |
| **掉** | quitar, perder | 忘**掉** · 扔**掉** |

## 想起来 vs 想出来

**想起来** = recordar algo que ya sabías. **想出来** = idear algo nuevo.

## Ejemplos

```ejemplos
现在出发还来得及。 | Si salimos ahora todavía alcanzamos.
时间来不及了，我们打车吧。 | Ya no alcanzamos, tomemos un taxi.
这里的夏天太热了，我真受不了。 | El verano aquí es demasiado caluroso, de verdad no lo aguanto.
我想起来了，他是我的小学同学。 | Ya me acordé: es mi compañero de primaria.
不管多难，你都要坚持下去。 | Por difícil que sea, tienes que seguir adelante.
这个办法是谁想出来的？ | ¿A quién se le ocurrió esta solución?
请把你的地址写下来。 | Por favor anota tu dirección.
```
