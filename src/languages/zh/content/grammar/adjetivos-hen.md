## Sin 是

Para describir no se usa 是. La frase básica es **sujeto + 很 + adjetivo**:

我**很**忙 = estoy ocupado. Aquí 很 casi no significa «muy»: es el enlace normal. ✗ 我是忙.

## Grados

| | | |
| --- | --- | --- |
| 不 + adj | no | 今天**不**冷 |
| 有点儿 + adj | un poco (queja) | 今天**有点儿**冷 |
| 很 + adj | (neutro) | 今天**很**冷 |
| 非常 + adj | muchísimo | 今天**非常**冷 |
| 真 + adj | ¡qué…! | 今天**真**冷！ |
| 太 + adj + 了 | demasiado / ¡tan…! | 今天**太**冷**了** |

## Preguntar

Con 吗 (你忙吗？) o con 怎么样 (天气怎么样？).

## Ejemplos

```ejemplos
我很忙。 | Wǒ hěn máng. | Estoy ocupado.
这件衣服太贵了。 | Zhè jiàn yīfu tài guì le. | Esta ropa es demasiado cara.
你的汉语真好！ | Nǐ de Hànyǔ zhēn hǎo! | ¡Qué bueno es tu chino!
今天非常热。 | Jīntiān fēicháng rè. | Hoy hace muchísimo calor.
这个菜很好吃。 | Zhège cài hěn hǎochī. | Este plato está muy rico.
今天有点儿冷。 | Jīntiān yǒudiǎnr lěng. | Hoy hace un poco de frío.
我的学校不大。 | Wǒ de xuéxiào bú dà. | Mi escuela no es grande.
```
